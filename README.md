# T-Shirt-Shop

A full-stack clothing e-commerce platform for T-Shirts, Shirts, Pants and
Customized T-Shirts. It includes a storefront, a customer account portal, an
admin portal, a Fabric.js T-Shirt designer with live pricing, and Razorpay
online payments alongside Cash on Delivery.

> **Status:** Phase 1 of 19 complete (architecture and design). Application code
> starts in Phase 2. See [PROJECT_PROGRESS.md](PROJECT_PROGRESS.md).

## Technology stack

| Layer | Technology |
|-------|-----------|
| Frontend | Angular, TypeScript, SCSS, Angular Material, RxJS, Reactive Forms, Fabric.js |
| Backend | Java 21, Spring Boot, Spring Security, Spring Data JPA / Hibernate, JWT, Maven |
| Database | MySQL 8 with Flyway migrations |
| Payments | Razorpay Standard Checkout, Razorpay Java SDK, Razorpay webhooks |
| Images | Secure local storage (default) or Cloudinary |
| Tooling | Git, GitHub, Postman, Swagger/OpenAPI, JUnit 5, Mockito |

## Prerequisites

- JDK 21
- Node.js LTS and npm (Angular CLI is installed per project)
- MySQL 8
- Git
- A Razorpay account in Test Mode

Maven does not need a separate install. The backend ships the Maven wrapper.

## Installation

```bash
git clone https://github.com/mukeshvakude/T-Shirt-Shop.git
cd T-Shirt-Shop
git checkout DEV
cp .env.example .env   # then fill in real local values
```

## Database configuration

```sql
CREATE DATABASE tshirt_shop CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'tshirt_app'@'localhost' IDENTIFIED BY '<strong password>';
GRANT ALL PRIVILEGES ON tshirt_shop.* TO 'tshirt_app'@'localhost';
```

Flyway creates all tables on backend start-up (Phase 2 onward).

## Backend execution

Available from Phase 3.

```bash
cd backend
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

Swagger UI will be at `http://localhost:8080/swagger-ui.html`.

## Frontend execution

Available from Phase 6.

```bash
cd frontend
npm install
npm start   # http://localhost:4200
```

## Razorpay test setup

1. Sign in to the Razorpay Dashboard and switch to **Test Mode**.
2. Generate a Key ID and Key Secret under Account & Settings, API Keys.
3. Add a webhook pointing to `https://<public-url>/api/payments/webhook` with a webhook secret. Subscribe to `payment.captured`, `payment.failed`, `order.paid` and `refund.processed`. For local testing, expose the backend with a tunnel such as ngrok.
4. Put `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET` and `RAZORPAY_WEBHOOK_SECRET` in `.env`.

The Key Secret and Webhook Secret stay on the backend and are never sent to Angular.
